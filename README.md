# CodeLogistic


Codelogistic is an educational web platform designed to support students and developers in learning and practicing 7 different programming languages. 
The platform focuses on providing a clean, accessible interface to explore code logic across multiple environments


Features

- Multi-Language Support: Comprehensive tools for Java, Python, JavaScript, C++, C#, Kotlin, and PHP
- Educational Focus: Built to simplify complex logic and provide a seamless learning experience
- Modern Interface: Responsive design ensuring accessibility across various devices
- Clean Architecture: Developed using ASP.NET MVC and Razor Views for scalable content delivery

Tech Stack

- Backend: ASP.NET MVC, C#
- Frontend: HTML5, CSS3, JavaScript
- Templating: Razor Views (.cshtml)
